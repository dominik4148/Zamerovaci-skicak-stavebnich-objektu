# Zápisník

Offline zápisník pro iPad (webová aplikace). Data se ukládají jen v iPadu.

## Nahrání na GitHub
1. Vytvoř nový repozitář a nahraj do něj celý obsah této složky (včetně složek `js` a `lib`).
2. V repozitáři: Settings → Pages → Branch `main`, složka `/ (root)` → Save.
3. Za chvíli poběží na adrese `https://TVOJE-JMENO.github.io/NAZEV-REPOZITARE/`.

## Instalace na iPad
1. Otevři adresu v Safari a jednou ji nech celou načíst (uloží se pro offline).
2. Sdílet → Přidat na plochu. Dál ji spouštěj z ikony na ploše.

## Aktualizace
1. V repozitáři: Add file → Upload files, přetáhni znovu celý obsah složky (soubory se stejným názvem se přepíšou) a dej Commit changes.
2. Při každé změně musí být v `sw.js` vyšší číslo verze (teď `zapisnik-v4`), jinak iPad použije starou uloženou verzi.
3. Na iPadu aplikaci zavři a dvakrát po sobě otevři – nová verze naskočí při druhém otevření.

## Záloha
Nastavení (ozubené kolo) → Vytvořit zálohu. Soubor `.zapisnik` si ulož do Souborů nebo na iCloud.
