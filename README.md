# Zaměřovací skicák – offline verze

Webová aplikace pro rychlé skicování půdorysů při zaměřování. Funguje i bez signálu.

Spuštění: GitHub Pages (Settings → Pages → Deploy from branch → main / root).
Na iPadu otevři adresu v Safari → Sdílet → Přidat na plochu. Pak spouštěj z ikony na ploše.

Aktualizace: nahraj nový `index.html` a v `sw.js` zvyš číslo ve VERSION (např. skicak-v2).
